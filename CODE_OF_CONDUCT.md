# Code of Conduct

## Our standard

This project is a technical collaboration space. Participants are expected to:

- discuss ideas and code with evidence, precision, and respect;
- critique behavior and implementation rather than people;
- disclose conflicts of interest and avoid presenting unverified CAD results as verified;
- protect private paths, credentials, customer models, and other sensitive data;
- keep issues and pull requests focused on reproducible engineering outcomes.

Harassment, discrimination, threats, deliberate disruption, credential sharing,
and publication of another person's private data are not acceptable.

## Scope

This standard applies to repository issues, pull requests, reviews, discussions,
and other project spaces. It also applies when representing the project elsewhere.

## Enforcement

Report conduct concerns privately to the repository maintainer through the contact
options on the GitHub profile. Include links or screenshots only when they do not
expose sensitive third-party data. Maintainers may edit or remove content, lock a
thread, reject a contribution, or temporarily or permanently restrict participation.

Reports will be reviewed for relevance and consistency. Retaliation against a
person who reports a concern is itself a violation.

## Attribution

This code of conduct is informed by the Contributor Covenant and adapted for the
CAD automation project's evidence and privacy requirements.
