Pack and Go 子进程是一次性 COM 封送后端，不是新增常驻服务。归属取决于实际 PID，不取决于 CreateObject/Dispatch 是否返回对象；未知快照、目标文档缺失、PID 不一致或超时都阻断，避免另一轮暂存/重试覆盖未确认的输出。2026 的清单依赖活动文档，回退明确激活指定源文件，并验证返回的文档路径。

comtypes 对文档数组的封送在本机报 KeyError(9)，回退通过同 PID 的 pywin32 观察器只读取得清单，实际写入仍隔离在子进程。只关闭本轮明确打开的文档；已有源文件和用户未保存文档不归属该子进程。

errors 与 warnings 分别使用本机官方 SDK 的两个枚举，原始数值保留，稳定机器错误码进入 Core/MCP。GetErrorCode2 区分警告与错误；无法取得完整证据仍需人工复核。
