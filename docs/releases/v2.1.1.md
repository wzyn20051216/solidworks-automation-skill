# v2.1.1 — 工程阶段复核

- **查看阶段复核**。在 CAD Studio 的任务执行区和队列中查看各阶段的验收条件、待确认事项和人工复核状态。
- **修改后复核受影响的结果**。修改工作台的需求或长、宽、高、壁厚，或在对话中明确指令修改需求或关键尺寸，都会标记相关旧结果。比如「把孔径改为 8 mm」从孔槽阶段起沿依赖关系标记下游，需求和基础建模可保留原状态。普通追问、假设和否定句不会触发标记。
- **保留历史**。旧文件及原复核记录仍可查看。对话变更成功入队后生效，复核状态在重启后可恢复。
- **修复桌面 Agent 启动**。Worker 会关闭非交互 Agent 的标准输入，避免启动器留下的输入管道阻塞任务。Codex 可从随安装包交付的技能目录运行，任务审批和沙箱策略照常生效。
- **识别本轮尺寸证据**。交付账本记录 JSON 测量报告的执行前哈希，新生成或内容有变化的报告才能用于尺寸验收。
- **保留追问空间**。下一轮对话使用历史消息摘要片段，完整诊断仍可在任务记录中查看。

## 下载与升级

- **CAD Studio**。下载 `CAD-Studio-2.1.1-Setup-x64.exe`。v2.1.0 用户可在 CAD Studio 检查更新，或关闭程序后在原安装位置运行新版安装器。便携版请解压到新目录。
- **MCPB**。在支持 MCPB 的客户端导入 `SolidWorks-Automation-Skill-2.1.1.mcpb`。如缺少 uv，运行 `winget install --id astral-sh.uv -e` 后重启客户端。带 `-smithery` 的包用于 Smithery 工具清单。
- **独立 Skill**。下载 `SolidWorks-Automation-Skill-2.1.1.zip`，导入其中的 `solidworks-automation` 目录。

安装版、便携版、Skill ZIP 和 MCPB 使用同版运行时。用 `SHA256SUMS.txt` 核对下载文件。原生操作仍需本机安装并许可 SolidWorks。
