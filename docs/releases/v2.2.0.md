# v2.2.0 — 实时预览、制图检查与连接可靠性

本版汇总 v2.1.1 之后的 #79、#80、#81、#86、#87、#88、#89、#90。独立 Skill、标准 MCPB、Smithery MCPB、CAD Studio 安装版及便携版使用同一套 v2.2.0 运行时。

## 新增与改进

- **SolidWorks 实时执行预览**：CAD Studio 可查看建模过程，只捕获目标 SolidWorks 窗口；抓取失败显示预览不可用，不回退到其他窗口或整个桌面。
- **AutoCAD 中文与原生预览**：改进中文字体选择，检查中文标题栏、尺寸标注、视口及原生导出结果。
- **DXF 制图检查报告**：按图幅和项目模板配置规则，生成可复核的检查报告；尺寸避让、文字重叠和制造放行继续由人工复核。
- **安装与任务可靠性**：加强安装保护、CAD 健康探测和执行结果容错。
- **Codex 只读任务**：明确选择 read-only 时保持只读，不再被升级成 workspace-write。
- **筋特征**：补齐 InsertRib 参数，按特征树差集返回本次新增筋；未创建时返回空，不把已有筋误报为新结果。保留 direction 的历史双侧厚度语义。
- **可选实例附着回退**：默认关闭。明确设置 `SW_ATTACH_EXISTING_DISPATCH=1` 后，可在 ROT 查询失败时尝试版本化 Dispatch，并核对 PID、实际版本及前后进程清单。附着保留用户窗口、文档和实例所有权；身份不符时停止，不自动重试或退出未知实例。不同安装环境下 Dispatch 仍可能启动其他进程，事后核验不能防止构造动作本身。
- **孔创建失败诊断**：圆孔切除返回空时提供 `SW_HOLE_NOT_CREATED`、失败后的草图/选择/实体状态和 `retryable=false`；不擅自反向切除或重复写操作。
- **保留阶段复核**：工作台或对话中的明确需求、关键尺寸修改继续标记受影响下游，普通追问不触发。

## 验证范围与已知限制

最近一轮真机验收以 SolidWorks 2026 SP1.1 为目标：筋的单双侧、第二筋和保存重开；16 个连接与窗口状态对照；10 个通孔成功对照及直接 API/MCP 失败诊断。验证记录见[筋特征](../rib-sw2026-regression.md)、[连接回退](../rot-sw2026-regression.md)、[重开通孔](../hole-reopen-regression.md)。

**#82 原报告的 SW2024 build 32.5.0 现象尚未确认修复，Issue 保持开放。** SW2026 回归通过不能代表该 SW2024 场景已解决。Codex 修复验证了最终沙箱参数选择；本机系统级沙箱对照未能取得有效隔离证据，不作额外隔离保证。

原生 CAD 操作仍需本机安装并许可相应软件。高级几何、不同模型与制造交付仍需按具体任务复核。

## 下载与升级

- **CAD Studio 安装版**：下载 `CAD-Studio-2.2.0-Setup-x64.exe`。v2.1.1 用户可检查更新，或关闭 CAD Studio 后在原安装位置运行新版安装器；升级验收覆盖原位安装和应用数据保留。
- **CAD Studio 便携版**：下载 `CAD-Studio-2.2.0-Windows-x64-Portable.zip`，解压到新目录，避免覆盖正在运行的程序。
- **独立 Skill**：下载 `SolidWorks-Automation-Skill-2.2.0.zip`，导入其中的 `solidworks-automation` 目录。
- **标准 MCPB**：在支持 MCPB 的 Windows 客户端中导入 `SolidWorks-Automation-Skill-2.2.0.mcpb`，再重启或重新连接 MCP 服务。
- **Smithery MCPB**：使用 `SolidWorks-Automation-Skill-2.2.0-smithery.mcpb`。

MCPB 仍通过 uv 管理 Python 3.12 和锁定依赖，不内嵌 Python。缺少 uv 时启动器会在 stderr 给出安装引导，保持 stdout 供 MCP 协议使用。可执行下列命令安装 uv，再退出并重开客户端；首次解析 Python 和依赖需要联网。

```powershell
winget install --id astral-sh.uv -e
```

用同一发布页的 `SHA256SUMS.txt` 核对下载文件。安装包的更新签名文件及 `latest.json` 随版提供，沿用既有更新公钥。
