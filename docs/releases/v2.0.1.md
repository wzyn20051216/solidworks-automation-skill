# v2.0.1 — 技能包与 CAD Studio 同步更新

技能原版本为 2.0.0，桌面端原版本为 0.3.4；从本版起，两者统一使用 2.0.1，避免最新 Release 缺少桌面更新清单或版本混用。

## 下载与更新

- **CAD Studio 安装版**：下载 `CAD-Studio-2.0.1-Setup-x64.exe`，关闭 CAD Studio 后运行安装程序。现有支持签名更新的桌面版本也可使用应用内检查更新；此前如果因最新 Release 缺少清单而更新失败，可直接下载安装包。
- **CAD Studio 便携版**：下载 `CAD-Studio-2.0.1-Windows-x64-Portable.zip`，解压到新的目录，再运行其中的 `CAD Studio.exe`。不需要另外导入技能包，已经内置同版运行时。
- **Agent 技能包**：下载 `SolidWorks-Automation-Skill-2.0.1.zip`，内含 `solidworks-automation/SKILL.md`、MCP 服务、脚本、依赖清单及安装器。可将整个 `solidworks-automation` 文件夹导入客户端。手动更新旧目录前先备份，保留自己的配置及模型；Git 安装的技能可继续使用安装器快进更新。
- **校验**：`SHA256SUMS.txt` 覆盖所有发布附件；安装包另带 `.sig`，`latest.json` 提供现有更新器使用的下载地址与签名。本版沿用 0.3.4 的更新公钥及应用标识。

原生 CAD 操作仍需要本机安装并许可的 SolidWorks。当前新增能力的真机验收目标是 SolidWorks 2026 SP1.1；Python/Node 等前提与按需环境准备见 README 和用户手册。

## 本版重点

- **交付真实性**（#52、#54、#68）：生产执行器统一执行本轮文件门禁；旧文件拒绝交付，缺基线、扫描截断或范围外文件转待复核。补齐 worker 执行前取证、扫描范围、文件类型覆盖和前端三态判断。
- **几何选边**（#67、#69）：修复边长和圆直径读取；覆盖短圆弧、整圆无顶点、反向参数、非有限数值、错误传播和 pywin32 兼容路径。
- **SW2026 装配与工程图增量**：包含主线已验收的装配体副本改名及配合引用核验、结构化 GD&T 出图、复合框、公共基准、投影公差带等改进；能力范围以 `capabilities.yaml` 和对应参考文档为准，设计与制造判断仍需工程复核。
- **API 查证**：包含本地帮助、官方文档、本地缓存及备用检索路径和按需环境准备；查证证据不会替代实际 CAD 验证。
- **发布一致性**：独立技能包和桌面内嵌技能使用同一份运行时清单，逐文件核对，包含 .NET 主机源码和 DRC 配置。技能 ZIP 带来源提交及逐文件 SHA-256 清单。

这些修复已完成 SolidWorks 2026 真机回归；发布流程还会验证 Python、前端、Rust、签名更新契约及便携/安装包启动。本版不宣称所有 SolidWorks 版本均已复测，也不将文件新鲜度视为尺寸或制造合格证明。
