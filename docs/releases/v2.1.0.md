# v2.1.0 - Skill、MCP 与五阶段 CAD 交付流水线

本版把同一轮能力同时交付为 Agent Skill、标准 MCP Bundle（MCPB）和 CAD Studio 桌面端。
三者版本号、运行时文件和交付门禁保持一致。

## 下载与升级

- **标准 MCPB**：下载 `SolidWorks-Automation-Skill-2.1.0.mcpb`，在支持 MCP Bundle 的客户端中直接导入。
- **Smithery MCPB**：下载 `SolidWorks-Automation-Skill-2.1.0-smithery.mcpb`，包含运行时实际的工具 `inputSchema`。
- **Agent Skill ZIP**：下载 `SolidWorks-Automation-Skill-2.1.0.zip`，包内入口为 `solidworks-automation/SKILL.md`。
- **CAD Studio 安装版**：下载 `CAD-Studio-2.1.0-Setup-x64.exe`，关闭旧版后覆盖安装。
- **CAD Studio 便携版**：解压 `CAD-Studio-2.1.0-Windows-x64-Portable.zip` 到新目录后运行。
- **完整性校验**：`SHA256SUMS.txt` 覆盖所有附件；安装包使用 `.sig` 签名，`latest.json` 提供应用内更新清单。

原生 SolidWorks 操作需要本机安装并许可的 SolidWorks。当前真机验收目标为
SolidWorks 2026 SP1.1；AutoCAD 2026 能力按 `pilot` 等级交付并保留人工复核。

## 本版重点

- **五阶段项目流水线**：需求、需求总结、三维设计、验证、工程图按顺序推进；上游需求改动会自动使下游确认失效。
- **GB 工程图强制门禁**：工程图阶段必须提交本轮 DXF；系统执行 12 项 GB 检查，缺少检查器、报告、项目或任一项失败均阻断交付。
- **AutoCAD 2026 增强**：补齐中文字体样式、真实尺寸、A3 图框、DWG 保存重开、DXF/BMP/PNG 导出和视口收敛校验。
- **预览质量门禁**：原生位图必须达到最小分辨率与墨迹占比，避免把最小化窗口产生的缩略图当作交付预览。
- **MCP 发布完整性**：MCPB 明确包含 `subskills/`、`references/` 和工程图 Schema；打包后验证入口、版本、必需文件与本地配置排除项。
- **实时可视化**：SolidWorks 执行步骤可推送结构化事件与主窗口快照，桌面端实时展示进度和最终交付证据。

## 验证范围

离线回归覆盖 Python、MCP 发现/完整模式、前端单测、Rust 单测、安装器安全边界、
GB 门禁和发布工作流契约。GitHub 托管 CI 不执行真实 SolidWorks/AutoCAD，
真实 CAD 结论只来自对应版本的维护者本机验收记录。
