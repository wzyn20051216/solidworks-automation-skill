# v2.1.0 — MCPB 与 LM Studio 本地助手

- **CAD Studio**：下载安装版 `CAD-Studio-2.1.0-Setup-x64.exe`。v2.0.1 用户可在 CAD Studio 检查更新，或关闭程序后在原安装位置运行新版安装器。便携版请解压到新目录。
- **MCPB**：下载 `SolidWorks-Automation-Skill-2.1.0.mcpb`，在支持 MCPB 的 Windows 客户端中导入。若日志提示缺少 `uv`，运行 `winget install --id astral-sh.uv -e`，退出并重开客户端。首次启动需要获取 Python 和锁定依赖。带 `-smithery` 的包用于 Smithery 工具清单。
- **独立 Skill**：下载 `SolidWorks-Automation-Skill-2.1.0.zip`，将其中的 `solidworks-automation` 目录导入客户端。两个 MCPB 和桌面包使用同版技能运行时。

CAD Studio 新增 **LM Studio 本地问答与任务规划**。在 LM Studio 0.4 或更新版本加载对话模型，启动本机 API，再到 CAD Studio 面板检查连接。问答支持上下文追问，任务规划会展示待确认事项、执行步骤和验收条件。计划供人工复核，实际 CAD 操作通过独立的 AI 执行对话提交。

原生 SolidWorks 操作仍需本机安装并许可。近期回归以 SolidWorks 2026 SP1.1 为基线，部分能力另有 2024 真机记录，详见仓库的 `capabilities.yaml`。未列出的版本和能力需要各自验证。

Windows 安装回归在 GitHub 托管的干净 Windows Server 2022 实例中运行，覆盖首次安装、启动、从公开 v2.0.1 安装版原位升级及应用数据保留。签名与更新清单另有自动校验。下载文件可用 `SHA256SUMS.txt` 核对。
