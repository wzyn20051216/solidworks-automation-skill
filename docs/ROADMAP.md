## 1. 原理演示类 skill（anatomy / machine 风格）

### 1.1 参考对象（已核实的事实）

- **Anatomy**（`wheresryan22/anatomy`）：把一个技术原理做成“真实可运行的等轴测交互对象”（SVG / SVG+WebGL / 3D beta）。
  关键理念：**图里每个数字都来自驱动零件运动的同一个小模型**；先收集真实数值、再造对象；用**几何互穿审计**（零件互相穿过）和
  无头浏览器截图做验证，并要求逐张读图确认。不需要 API key，仅用 Node 内置模块。
- **Machine**：**未找到独立仓库**。仅见 `wenyen-hsu/skill-compare`（“同一句话，两个 skill：anatomy vs machine”）。
  → **待确认来源**：需要你提供链接后再评估，本路线图不对其做法下结论。
- 许可证未核对：**只借鉴思路，不拷贝其 kit 代码**。

### 1.2 我们要吸收的点

1. **单一事实源**：演示读取与 CAD/核验同一份参数模型（`mechanism-spec`），演示里的数字可追溯到模型字段，杜绝“图是图、算是算”。
2. **审计内置**：复用我们已有的干涉/几何证据（`solidworks_interference_check`、DRC 沉头朝向等）做“演示自身的几何自检”。
3. **可降级**：无 WebGL 也可读；尊重 reduced-motion；纯静态 HTML/SVG，无外网依赖。
4. **边界**：演示一律标 `demo-showcase` / `isDemo: true`，**不得进入交付判断**（与 `SKILL.md` 既有规则一致）。

## 2. 电机扭矩核验（P0/P1 已实现为 `pilot`，P2 起 `planned`）

> 已落地：`scripts/drive_sizing.py` + DRC 规则族 `DRC-DRV-001…005/900`，详见 [`references/drive-sizing.md`](../references/drive-sizing.md)。下表 P0、P1 已完成。

目标：给定机构与运动曲线，判断所选电机/减速机**是否满足场景**，并给出余量与最危险的约束项。

**输入（`drive-spec`，声明式 JSON，可由自然语言经代理生成）**
- 负载：质量、安装方位/倾角、摩擦系数、外力、行程与运动曲线（梯形/S 曲线：距离、时间、加减速）。
- 传动：直驱 / 减速比 `i` 与效率 `η` / 丝杠（导程、效率、丝杠惯量）/ 皮带轮（半径）/ 齿条。
- 电机：额定转矩、峰值转矩、额定/最高转速、转子惯量、有无抱闸；安全系数。

**判据（纯函数）**
- 负载力 `F = m·g·(sinθ + μ·cosθ) + F_ext (+ m·a)`；折算到电机轴：丝杠 `T = F·p/(2π·η)`，减速/皮带 `T = F·r/(i·η)`。
- 加速转矩 `T_acc = (J_motor + J_reflected)·α`；峰值 `T_peak = T_load + T_acc`；各运动段转矩 → **均方根转矩** `T_rms`。
- 校核：`T_peak·SF ≤ T_max`、`T_rms ≤ T_rated`、`n_max ≤ 电机最高转速`、**惯量比** `J_L/J_M ≤ 阈值`（阈值进 Profile，随厂商/场景可调）、
  垂直轴必须有抱闸/自锁、功率与再生能量提示。
- 后续：丝杠临界转速与压杆稳定、皮带张力、寿命。

**输出**：沿用 DRC 报告体系（`checks` / 指纹 / 让步单 / 风险分 / 条款出处），新增规则族 `DRC-DRV-*`；每项给“余量 %”与“控制性约束”。

| 期 | 内容 | 验收 | 规模 |
|---|---|---|---|
| P0 | 纯函数公式 + **手算锚点单测**（教科书算例，注明出处） | 锚点全部命中；边界（零惯量/负载/超速）有断言 | M |
| P1 | 并入 DRC：`DRC-DRV-001…`；Profile 阈值；MCP 经 `cadstudio_check_drc` 或独立工具暴露 | `validate_mcp` 登记；让步/基线 diff 可用 | M |
| P2 | **从 3D 自动取参**：质量用 `solidworks_mass_properties`、行程用 `sw_measure`/包围盒/配合极限（上游已验证的测量工具） | 取参→核验端到端；缺数据则 `blocked` 并说明缺什么 | M |
| P3 | **声明式电机/减速机目录**：用户提供厂商数据并**带出处与版本**，禁止代码内置无法核实的型号参数；“满足条件的最小规格”推荐并列出假设 | 目录条目缺出处→拒绝加载 | M |

## 3. 气缸行程 / 出力 / 稳定性核验（`planned`）

目标：根据**气缸参数与 3D 尺寸**核验“这个气缸能不能在这个场景里干这件事”。

**输入（`actuator-spec`）**：缸径 `D`、杆径 `d`、选定行程 `S`、工作压力 `P`（表压）、负载力/质量与方向、安装方式与端部约束、所需运动时间、节拍、管路内径与长度、缓冲形式；
**所需行程来自 3D**：装配中两个工位的实测距离（配合极限 / `sw_measure`），并核对伸出态包络与周边干涉。

**判据（纯函数）**
1. **出力**：推出 `F = P·πD²/4`，拉回 `F = P·π(D²−d²)/4`；用**负载率**（静载/动载/高速分档，进 Profile）校核 `F_load/F_theory`，给出余量。
2. **行程**：`S ≥ S_需 + 余量`；与标准行程系列比对，非标准给出提示（成本/交期）；伸出态不得超出 3D 包络。
3. **杆稳定性（压杆）**：Euler 临界载荷 `F_cr = π²EI/(K·L)²`，`I = πd⁴/64`，`K` 随安装方式；安全系数进 Profile。长行程 + 受压是首要风险。
4. **速度与缓冲**：`v = S/t`、由流量 `Q = A·v` 反推阀/管路能力；行程末端动能 `½mv²` 与缓冲能力（来自目录）比较。
5. **耗气量**：按缸容积与节拍估算（折算大气压状态）；与气源能力比较。
6. **侧向力 / 导向**：存在悬臂或偏载但未声明导向 → 警告。

**输出**：同样走 DRC 体系，规则族 `DRC-PNE-*`，并与 §2 共享“控制性约束 + 余量”表达。

| 期 | 内容 | 验收 | 规模 |
|---|---|---|---|
| P0 | 纯函数 + 手算锚点单测（出力/压杆/耗气） | 锚点命中；`d≥D`、零压力等非法输入被拒 | M |
| P1 | 并入 DRC：`DRC-PNE-*`、Profile 阈值、MCP 暴露 | 同 §2 P1 | M |
| P2 | **3D 取行程与包络**：实测工位距离 → `S_需`；伸出态包络做干涉检查（复用 `solidworks_interference_check`） | 行程不足/干涉均能被发现 | M |
| P3 | **声明式气缸目录**（缸径/杆径/标准行程系列/缓冲能力，**带标准或厂商出处**；ISO 15552 等系列先对照标准原文再入库，不凭记忆写表） | 缺出处→拒绝加载 | M |
| P4 | 与演示联动（§1 P2 的气缸回路图读数取自本核验） | 单测断言一致 | S |
