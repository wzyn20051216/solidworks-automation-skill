- `SetupSheet6`、`NewSheet4`

- `CreateDrawViewFromModelView3`
- `InsertModelAnnotations3/4`
- `InsertBomTable4`
- `CreateSectionViewAt5`、`CreateDetailViewAt4`
- `InsertDatumTag2`、`InsertSurfaceFinishSymbol3`、`InsertWeldSymbol`
